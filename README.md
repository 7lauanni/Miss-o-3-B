# Missao 3B

Projeto desenvolvido durante as aulas de programação, nas linguagens de programação  HTML,CSS e JAVA SCRIPT. 
O presente projeto é uma história com varios caminhos a ser percorrido pelo usuário.
Feito por Lauanni Silva Dias e Maria Heloisa de Araujo Matos do 3B.

A historia é sobre: O Baile das Máscaras Vazias

 O Mistério: Uma vez a cada cem anos, um castelo flutuante aparece nos céus e convida a elite do reino para um baile de máscaras. No final 
 da noite, o castelo desaparece, mas desta vez ele continuou lá. Quando os guardas entram, encontram todos os convidados em pé, dançando em 
 silêncio, mas suas máscaras estão vazias por dentro: seus rostos e identidades foram "comidos".
 A Investigação: Um caçador de monstros e uma maga da corte precisam entrar no salão e descobrir qual das pessoas dançando é, na verdade, a
 criatura disfarçada que orquestrou o banquete, antes que o castelo desapareça para sempre.
